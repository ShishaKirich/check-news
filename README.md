# check-news — UI-автотесты сайта Финансового университета

Набор автоматизированных UI-тестов для сайта [fa.ru](https://www.fa.ru/) на
**Selenium** и **pytest**. Проверяет доступность страниц, корректность заголовков
и работу навигации по меню.

## Что проверяется

- Загрузка страницы кафедры информационной безопасности и наличие ожидаемого текста
- Корректность заголовка страницы (`<title>` и `<h1>`)
- Работа бургер-меню и правильность ссылки в пункте «Университет»

## Технологии

`Python` · `Selenium` · `pytest` · `webdriver-manager`

## Запуск

```bash
pip install selenium pytest webdriver-manager
pytest test_fa.py -v
```

> Драйвер Chrome ставится автоматически через `webdriver-manager`. Тесты зависят
> от текущей вёрстки сайта fa.ru — при её изменении локаторы может потребоваться
> обновить.
